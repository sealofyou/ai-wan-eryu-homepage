# V0.10 作品集重做实施计划

## Task 1：锁定现有基线

新增作品集结构测试，要求：

1. 页面从 `projects` collection 读取公开项目。
2. 公开项目按推荐状态和更新时间排序。
3. 每个项目链接到自己的站内档案。
4. 页面不再使用旧的整屏 Hero、通用流程图封面和静态项目数组。
5. 首屏包含短介绍区和重点项目区。

先运行测试并确认它在旧实现上失败，再开始页面修改。

## Task 2：建立作品集视图数据

给项目 collection 增加向后兼容的可选 `cover` 与 `coverAlt` 字段，再在作品集页面中读取并筛选公开项目。

建立轻量页面视图：

- `featuredProject`：首个推荐项目，若没有推荐项目则使用最新公开项目。
- `projectIndex`：全部公开项目，推荐项目优先，其余按更新时间倒序。
- 项目数量、日期和结果数据均来自内容文件，不在模板中重复硬编码。

## Task 3：实现真实作品集页面

重写 `src/pages/portfolio.astro`：

- 删除旧封面图和静态 `projects.ts` 依赖。
- 实现短介绍、重点项目和项目索引。
- 使用真实首页截图作为重点项目视觉证据。
- 保留现有站点导航和项目详情路由。

重写 `global.css` 中仅属于旧作品集的样式，不调整首页桌面样式和项目详情页样式。

## Task 4：生成并优化真实截图

从 V0.9 默认首页捕获稳定横屏截图：

- 不显示调试 UI。
- 保持 16:10 或接近的展示比例。
- 转为 WebP 并限制资源体积。
- 验证页面使用 `object-fit: cover` 或固定比例容器，禁止拉伸。

## Task 5：视觉与交互验证

至少检查：

- 1440×900
- 1920×1080
- 2048×1152
- 1024×768

验证标题、截图、详情入口和项目索引没有重叠、截断或横向溢出。使用视觉评审结果指导迭代，分数达到 90 后停止视觉修改。

同时对首页执行 V0.9 基线像素比较，要求首页零像素差。

## Task 6：完成 Gate

依次运行：

1. `npm test`
2. `npm run check`
3. `npm run build`
4. `npm run check:assets`
5. `npm run check:models`
6. `npm run check:release`
7. `git diff --check`

更新 `IMPLEMENTATION_RESULT.md`，记录作品集变化、截图资源大小、测试数量和视觉验收结果。

完成后提交并推送 `codex/v0.10-portfolio-redesign`。本地验收前不合并到 `master`，不部署公网。
