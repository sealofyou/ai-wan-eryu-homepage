# AI玩尔玉 3D 桌面视觉救援 Brief

## 结论

本轮保留整屏 3D 桌面，但不保留现有镜头与视觉分配。主屏成为第一阅读目标，副屏承担内容入口，其他互动降为彩蛋。实现采用一条路线，不制作三套代码页面。

这不是继续逐件换模型。救援范围是镜头、物件比例与数量、统一材质、屏幕 UI、内容聚焦转场和互动主次。

## 证据与路线选择

| 路线 | 结论 | 证据 |
| --- | --- | --- |
| A. 整屏软 3D 桌面翻修 | 采用 | 当前基线已保留真实内容和完整交互合同；主要失败可明确定位到主屏过小、无效空间过多、材质不统一和屏内排版过密。 |
| B. 可见 DOM 身份区 + 右侧 3D | 不采用 | David Heckhoff 的大字、留白和软 3D 值得借，但可见 DOM 会改变“内容存在显示器内部”的现有合同，也会让本轮变成新首页架构而不是救援。 |
| C. Bruno Simon 式完整沉浸世界 | 不采用 | 完整世界需要从入口、操控、空间资产到内容发现全部围绕一个机制重做；当前任务既不允许扩展到虚构世界，也没有相应资产和交互预算。 |

## 1440×900 构图

- 主屏含音箱：视口宽 38%–44%，中心略偏右；屏内标题成图高度至少 32px。
- 副屏：视口宽 13%–15%，紧贴主屏左侧，不再以大透视角收窄。
- 机箱：视口宽 10%–12%，保留便利贴与小型 Q 版摆件。
- 台灯与徽章板：合计视口宽 14%–16%；只保留一块板，允许右缘轻微裁切。
- 桌垫与键鼠：占画面下方 28%–32%；桌体前沿不得成为大面积主色块。
- 主屏与副屏合计至少占视口宽度一半。第一眼先读屏幕，再发现物件。

## 物件与互动主次

保留六组：

1. 主屏 + 音箱。
2. 竖向副屏。
3. 机箱 + 便利贴 + Q 版摆件。
4. 键盘。
5. 鼠标 + 一整张浅色桌垫。
6. 台灯 + 单块徽章板。

删除第二块大洞洞板。桌垫上的移动、画笔、留言、清空继续存在，但改为低对比嵌入式标签。主流程只有副屏切换和屏内内容浏览；键鼠拖动、书写、格言、徽章和灯光均为次级互动。

## 美术语言

- 色板只使用暖木、炭黑、暖白、低饱和绿；其他颜色只出现在屏幕内容内。
- 设备以哑光塑料为主，降低金属度；所有主体使用圆角、软阴影和一致的粗糙度范围。
- 背景墙使用偏暖的米灰，不加纹理贴图；桌面木色不再偏橙。
- 灯光由暖色重点光、柔和环境光、克制屏幕补光组成；不使用 bloom、霓虹、粒子或蓝紫渐变。
- 主屏继续使用已存在的公开主形象资产，但通过留白、裁切与纸面色统一，而不是再增加新形象。

## 屏幕 UI 与转场

- 主屏默认只放品牌、大标题、短简介和两条真实状态；不添加营销描述。
- 副屏保持文章、分享与活动、最近在做三个真实入口，但减少装饰块，强化日期/标题和当前选中态。
- 内容列表与详情继续使用现有 CanvasTexture 与状态模型，命中区域合同不变。
- 点击副屏后，镜头在约 420ms 内柔和聚焦主屏，同时主屏从低亮度淡入新内容；返回首页时回到总览镜头。
- `prefers-reduced-motion` 下禁用镜头推近与淡入，只保留立即状态切换。
- WebGL 失败继续使用现有 fallback；生命周期清理、GLB 可选鼠标和所有公开内容路由保持不变。

## 工程边界

允许修改：`layout.ts`、renderer、场景装配的镜头过渡、物件视觉工厂、屏幕画布和桌面 CSS。

不改：Astro 内容集合、公开文案事实、路由、状态模型语义、鼠标/键盘/书写/留言交互合同、模型清单与手机版边界。

## TDD 与验收

先更新或新增回归测试，再改实现：

1. 镜头距离、主屏/副屏相对比例与单块徽章板约束。
2. 六组物件和原有交互装配仍存在。
3. 主屏 Canvas 字号与内容边界足以在 1440×900 成图中阅读。
4. 内容状态切换会触发主屏聚焦，返回首页恢复总览。

最终 Gate：

- `npm run verify:release` 通过。
- 1440×900 与 1920×1080 截图中六组物件在画面内，主屏宽占比达到 38%–44%。
- 副屏切换、屏内返回、鼠标与屏幕光标同步、键盘拖动、书写/清空、留言、格言、徽章和台灯交互通过真实浏览器验证。
- 控制台 0 error；WebGL canvas 非空；常驻帧率开发机实测不低于 45fps。
- visual-verdict 达到 90 才可称为视觉 Gate 通过；未达标继续迭代并记录仍存问题。

## 明确不做

不做手机版，不做 G502 或 img2threejs，不新增虚构项目/活动/徽章故事，不升级依赖，不部署，不合并 `main` / `master`。
