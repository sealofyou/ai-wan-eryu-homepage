# AI玩尔玉个人主页内容接入设计

本文覆盖 `2026-07-17-content-migration-design.md` 中关于完整正文存放位置和桌面内容接入方式的旧结论；旧文档继续作为历史内容迁移记录保留。

## 当前状态

- 已确认的 3D 桌面主页是视觉基线，不重新设计构图。
- 飞书知识库 `AI玩尔玉公开内容库` 已创建并开启未登录公开阅读。
- 飞书目前只有 `文章`、`分享与活动`、`项目与作品`、`时间笔记`、`关于与合作` 五个空入口，没有接入真实文章或活动。
- 当前 3D 场景仍在 `src/desktop/scene.ts` 中硬编码三条演示内容，没有读取 Astro Content Collections。
- 站内已有文章和时间笔记集合，但文章没有列表页，也没有接入桌面副屏和主屏。

## 不可变视觉基线

本次内容接入不得改变：

- 桌面构图、相机位置和响应式横屏取景。
- 左侧竖屏的尺寸、角度、卡片样式和三段式结构。
- 中间主屏的外观、个人介绍首页和屏幕材质风格。
- 机箱、便利贴、小洞洞板、大洞洞板、台灯、键盘、鼠标和桌垫控制键。
- 已经通过测试和截图确认的键鼠拖动、留言、绘制和彩蛋交互。

只有屏幕中的内容和点击后的屏幕状态可以扩展。

## 内容入口

左侧竖屏继续保留三个固定模块，模块名称允许在不改变布局的前提下调整：

1. `文章`
2. `分享与活动`
3. `最近在做`，后续可承载项目或当前状态

三个模块是栏目入口，不是一篇具体内容。内容增加后，不继续向副屏堆叠卡片。

## 主屏交互

### 默认状态

主屏继续显示现有个人介绍和当前状态，不做视觉重排。

### 文章状态

1. 点击副屏 `文章` 后，主屏切换为按日期倒序排列的文章列表。
2. 主屏一次展示有限条目，通过鼠标滚轮和屏幕内翻页控制浏览更多文章。
3. 每条文章显示日期、标题、一句话摘要和分类；封面为可选项。
4. 点击文章后，主屏切换为文章预览，显示标题、日期、分类、封面和 100 至 200 字预览。
5. 预览页提供 `返回文章列表` 和 `阅读全文`。
6. 完整正文不在 3D 主屏中渲染。

### 分享与活动状态

1. 点击副屏 `分享与活动` 后，主屏显示按日期倒序排列的活动列表。
2. 点击活动后，主屏显示活动摘要、代表图片、日期、地点以及当前包含的资料类型。
3. 预览页提供 `返回活动列表` 和 `查看完整活动`。
4. 完整活动记录、图片、分享稿、相关资源和复盘由飞书活动目录承载。

### 项目与当前状态

第三个模块一期继续保留现有 `最近在做` 能力。项目列表与项目详情不是本次内容接入的阻塞项，后续复用同一套列表、预览和完整内容跳转模型。

## 完整内容承载

一期采用：

- 主屏负责栏目列表和内容预览。
- `阅读全文` 在新标签页打开公开飞书文章。
- `查看完整活动` 在新标签页打开对应的公开飞书活动目录。
- 不使用 iframe，不在浏览器端调用需要凭据的飞书 API。

后续增加站内阅读页时，可以把目标地址切换为 `/articles/<slug>/` 或 `/activities/<slug>/`，不修改桌面入口和主屏交互。

## 本地内容记录

飞书保存完整正文，本地 Markdown 只保存网站展示和路由所需信息，不另建重复的预览文档。

文章记录至少包含：

```yaml
title: "文章标题"
date: 2026-07-23
category: "AI 实践"
description: "文章列表中的一句话摘要。"
preview: "主屏预览中使用的 100 至 200 字内容。"
cover: "/content/articles/example.webp"
target: "feishu"
externalUrl: "https://my.feishu.cn/wiki/..."
featured: false
draft: false
```

活动记录在上述字段之外增加：

```yaml
location: "活动地点"
images: []
resources: []
```

封面和公开展示图片优先保存在站点本地，避免依赖临时签名地址。

## 同步规则

飞书是完整内容事实源，本地内容记录是网站发布索引。

- 每周一上午 10 点运行 `个人主页飞书内容巡检` 自动化。
- 先比较飞书节点 token、修改时间和本地同步状态。
- 没有变化时不读取全文、不修改项目、不构建。
- 有变化时只读取新增或修改的文档。
- 自动字段和人工字段分离；不得覆盖已经确认的摘要、预览、封面、分类和推荐状态。
- 内容接入 schema 尚未建立时，只报告变化，不自行生成不兼容文件。
- 用户可以随时要求 `立即同步个人主页内容`，手动触发相同流程。

## 一期实现范围

1. 把桌面内容从 `scene.ts` 的硬编码数组移到独立内容数据层。
2. 扩展 Astro 内容 schema，支持文章和活动的预览、封面、目标类型及外部链接。
3. 保持副屏造型不变，将三个卡片接为固定模块入口。
4. 在现有主屏材质中实现栏目列表、内容预览、返回和完整内容跳转。
5. 文章和活动为空时提供克制的空状态，不用虚构内容填充。
6. 保留现有个人介绍首页和全部桌面交互。
7. 增加内容排序、状态切换、链接和回退行为测试。
8. 运行测试、Astro 检查、构建和桌面横屏截图验证。

## 暂不实施

- 不迁移旧博客全文。
- 不为填满页面而创建文章或活动。
- 不实现手机版内容交互。
- 不制作站内完整文章阅读模板。
- 不自动部署或覆盖当前线上版本。
- 不修改作品集、合作页和时间笔记的现有范围。

## 验收标准

- 默认打开主页时，视觉效果与当前确认版本一致。
- 点击副屏模块后，只改变屏幕内容，不改变场景构图和物件。
- 文章和活动可以按日期浏览、进入预览并返回列表。
- 完整内容链接在新标签页打开，链接不可用时给出明确状态。
- 没有真实内容时不展示伪造文章或活动。
- 现有桌面测试全部通过，新增内容交互有自动化测试覆盖。
- `npm test`、`npm run check` 和 `npm run build` 全部通过。
