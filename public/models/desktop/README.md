# 桌面 GLB 资产

本目录只保存经过来源、尺寸、方向和运行预算检查的桌面物件模型。

## gaming-mouse.glb

- 用途：V0.5 鼠标 GLB 管线的内部试验模型。
- 来源：仓库脚本自建的通用游戏鼠标几何，不对应具体品牌或市售型号。
- 生成命令：`npm run generate:mouse-model`
- 坐标：Three.js Y 轴向上，鼠标前端朝向 Z 轴负方向，原点位于物件交互容器中心。
- 材质：仅使用嵌入 GLB 的纯色 PBR 材质，无外部纹理请求。
- 授权边界：自建几何可随本项目使用；后续替换为外部或 AI 生成模型时，必须重新记录来源、套餐、生成日期、输入素材权利和授权条款。
- 运行边界：模型只负责视觉，点击和拖拽继续使用独立简化代理。

默认页面不会请求该文件。只有地址显式包含 `?mouse=glb` 时才会加载；加载失败自动保留程序化鼠标。

## 新资产进入条件

1. 单个 GLB 不超过 `3 MB`，普通物件优先控制在 `1 MB` 内。
2. 修正比例、原点、法线、材质和朝向。
3. 删除看不见的几何体、重复材质和无用动画。
4. 提供独立交互代理，不把高面数网格直接当点击碰撞体。
5. 在默认、加载成功、加载失败和页面卸载路径下完成测试。
