## 可行性判断与证据

可以尝试做成结构可信的独立网页3D鼠标；现有素材足够定义主视角的轮廓和分件，但不足以承诺全角度工业级复刻。最终精细度要由几何样件证明，不能用“模型格式为GLB”或审查分数代替。

- 现有 `src/desktop/objects/mouse.ts` 已将视觉层与拖动容器、命中代理、光标映射及资源清理分开，可以只替换视觉模型。

- 仓库历史评估记载过同类鼠标试验，未达到默认接入门槛，卡点是掌托/前键曲面连续性、滚轮井、DPI区和侧键。因此本次要重建这些关键结构，不直接沿用旧候选或自动生成器初稿。

## 鼠标的制作目标

| 部分 | 照片直接支持的结构 | 制作要求 |
| --- | --- | --- |
| 整体外形 | 前窄后宽、左右非对称、左侧外扩，掌托为连续隆起曲面 | 从截面与轮廓建立主体曲面，轮廓不以两个椭球代替 |
| 左右主按键 | 两块独立长面板，后缘为斜向分件线 | 按键和掌托分开建网格，保留清楚但克制的缝隙与倒角 |
| 中央区域 | 独立窄桥、下沉滚轮井、滚轮后方连续两个控制部件 | 先做出凹槽与部件高低关系，再做表面质感；不能只贴一条黑线 |
| 滚轮 | 独立轮体及可辨识的横向槽纹、两侧支承关系 | 用少量网格表达轮圈与槽纹，避免密集微几何 |
| 左侧区域 | 拇指托、侧面按钮和阶梯式侧壳 | 主视角必须读得出侧向外扩，侧键不能直接粘在光滑球面上 |
| 后掌托 | 隆起曲面与斜向/弯折接缝 | 用连续法线维持反射，不出现无意折线或互相穿插 |
| 品牌 | 原照片有厂商G标识 | 删除厂商品牌，使用已有Eryu折角E标志；不新增品牌字样或发光Logo |

材质分为干净的黑色塑料、局部握持面、滚轮金属及低对比Eryu丝印。照片中的灰尘、污渍与磨损不复刻。保持原桌面无长线缆的边界，鼠标只表达前端接口/短出线护套，不增加跨桌面动态电线。

## 工程与资源目标（待实测，不是已达成数据）

| 项目 | 打样预算 |
| --- | --- |
| 资产格式 | 独立GLB，模型、材质与应用交互分离 |
| 模型体积 | 目标不超过500KB；超出时先查隐藏面、重复网格与纹理，不自动放宽预算 |
| 三角面 | 初始目标1万至2万，优先投入主体曲率与大轮廓 |
| 材质/绘制批次 | 少量共享材质；尽量合并同材质静态部件，目标不超过约10批次 |
| 纹理 | 0–1张512级图集为起点，禁止加载原始4MB照片；不使用4K贴图 |
| 默认主页 | 未选候选时不请求新模型；首页JS继续遵守650KB既有预算 |
| 操作 | 继续使用低复杂度命中代理，保留拖动边界与主屏光标同步；不让精细网格逐帧参加全部射线检测 |
| 流畅度 | 同一设备比较原版与候选的加载和帧时间；目标60fps，不能只用开发机一次FPS作普遍保证 |
| 生命周期 | 模型加载失败回退，卸载中止迟到加载，释放几何/材质/纹理 |

## 制作与验收顺序

1. **几何打样**：只做鼠标，统一中性光和素色材质。提供与图2接近视角、左侧、后方三张近景及原桌面正常尺度视图。先检查轮廓、拇指托、主按键分件、掌托曲率和滚轮井。
2. **表面与品牌**：几何方向被认可后再加入材质、Eryu标识和克制细节。亮面不能遮掩错误的曲面；不得用照片贴图伪装结构。
3. **独立网页候选**：接入显式预览入口，保留原鼠标与桌面；验证拖动/光标、体量与接触关系。
4. **资源检查与交付**：报告实际KB、三角面、纹理与绘制批次，记录同环境性能对比，再由用户评价是否达到需要的真实设备感。

本轮不制作显示器，不改镜头、不重排屏幕、不新增分享/App页面，不合并或部署。模型未产出前不宣布“效果已实现”。
