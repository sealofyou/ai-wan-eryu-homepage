# 首轮资产清单｜秒哒参赛版

## 上传原则

上传的是“告诉秒哒该做什么”的参考资产，不是让它把图片铺成背景。每张图只说明物件关系、人物形象或品牌标识；生成结果仍必须是独立的可交互场景。

## 必传资产

| 本地文件 | 用途 | 使用边界 |
| --- | --- | --- |
| `reference/desktop-homepage-composition-approved-v1.png` | 构图、物件位置、画面密度的最高优先级参考 | 不得直接充当页面背景或完整截图热点图 |
| `reference/real-desk-photo.jpg` | 真实设备关系、左侧机箱与屏幕、桌垫、右侧区域的空间来源 | 不追求写实复刻，不从照片臆造未确认细节 |
| `reference/main-avatar-v1.png` | 中间主屏个人介绍中的人物形象 | 只在主屏内部使用，不做全屏大头像 |
| `reference/q-avatar-v1.png` | 机箱顶部的小型 Q 版摆件或彩蛋 | 只能作为小摆件，不替代主视觉 |
| `reference/eryu-wordmark-board-v1.png` | Eryu 字标、E 形符号在音箱、设备和徽章上的用法 | 不把字标做成页面顶部导航或科技感水印 |
| `reference/mouse-logitech-g502-primary-v1.jpg` | img2threejs 首个物件的主参考图，确定 G502 轮廓、分块、按键、滚轮、侧翼和线缆出口 | 忽略灰尘、磨损与背景；删除 G 标，替换为尔玉 E 标志 |

## 后续按需补充的资产

- 键盘正面与斜侧照片：仅用于下一轮细化键帽、轮廓与配色。
- G502 正上方、左侧和右侧照片：主参考图不足以证明隐藏结构时再补充，不阻塞第一轮 blockout。
- 洞洞板徽章、贴纸、活动合影或实物照片：每项必须有可公开确认，并附一条对应故事或链接。
- 每日短句：纯文本即可，不需要先设计成图片。

## 不上传

- API Key、服务器信息、IP、SSH 配置、内部文档截图、未公开聊天记录。
- 未取得公开许可的活动照片、他人头像、合作资料或品牌标志。
- 当前 Astro 源码压缩包、Git 目录、构建产物和环境文件。

## 生成代码资产

img2threejs 的鼠标生成物保存到 `modeling/img2threejs/mouse-g502/`。只有通过独立截图对照验收的 `mouse-g502.ts`、必要纹理和适配说明可以交给秒哒；评估文件、过程截图和完整本地工程不进入秒哒运行目录。
