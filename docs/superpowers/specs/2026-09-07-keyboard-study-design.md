# 键盘样件与桌垫控件精简

状态：用户已认可“先键盘”的方案，并要求同时移除桌垫四个实体按钮，允许执行者判断具体键盘制作方式。

保持现有104键布局、宽键比例、深色键帽/浅色外壳/低饱和绿强调键。采用程序化硬表面键帽与浅凹顶面，不照搬未知型号，不调用生图或未知高模。重点是让按键、定位板、上下壳之间的装配关系可信，而不是新增亮光。

实现选择：单个连续键帽网格替代两层圆角盒，按键类合并几何；文字使用一张本地生成图集并贴合曲面。与逐键独立材质相比可减少纹理和绘制调用；与全键盘GLB相比保留已有键位数据和可编辑性，不增加加载格式。

独立样件先用中性环境查看完整斜侧/俯视/前沿/侧面，素模检查轮廓，材质检查装配与文字。不把背面、接口或机械轴体做成没有照片支持的装饰。

候选桌面仍保持原镜头、X/Z关系和拖动范围；视觉层Y仅校正键盘落垫。主屏、竖屏、鼠标已认可外形不变。四个桌垫实体按钮在当前组合候选中不创建任何几何、标签或命中体，不用新图标替代；底层能力与既有无障碍键盘入口留存，等待后续交互整理。原主页对照、右上便利贴、机箱与台灯不在本轮改动范围。

验收：完整键盘可见、浅凹/收分/接缝无穿插、文字不漂浮或破碎，实际键盘拖动不回退；<=30000三角面/8材质，默认静态JS<=625000字节；完整release Gate、真实浏览器与异模型视觉复核后交本地观看，不合并部署。

实施清单见 `docs/superpowers/plans/2026-09-07-keyboard-and-controls.md`。
