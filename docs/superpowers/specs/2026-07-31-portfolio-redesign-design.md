# AI玩尔玉作品集重做设计

## 目标

把当前以整屏人像海报为主的作品集，改成可以直接浏览真实项目的“项目索引 + 项目档案”。

作品集首先回答三件事：

1. 尔玉实际做了什么。
2. 在项目中解决了什么问题、承担了什么工作。
3. 访客可以在哪里继续查看过程和结果。

## 当前问题

- 整屏暗色 Hero 占据首屏，真实项目在首屏不可见。
- Hero 文案容器同时使用固定最大宽度和随视口增长的左右内边距，宽屏下内容宽度被压缩，中文变成一字一行。
- 巨幅人像、竖排标题、暗色遮罩和通用流程图互相争夺注意力。
- 页面中的项目是静态文本行，没有证据图、详情入口和完整项目档案。
- 页面表现更接近宣传海报，不适合项目的扫描、比较和持续增加。

## 已确认边界

- 保持首页、3D 桌面、文章、活动、项目详情页和公网版本不变。
- 不制作额外的方案预览网页，直接在真实作品集页面上实现。
- 不等待用户批量补资料；首版只使用已经公开且可验证的内容。
- 不使用未确认项目、通用占位图或“内容整理中”凑数量。
- 不新增依赖；项目 collection 只增加向后兼容的可选封面字段。
- 本期优先桌面横屏；普通内容页仍需在窄屏下正常阅读，但不实现独立手机桌面。

## 方案选择

### 采用：项目索引 + 项目档案

顶部使用短介绍区，首屏立即展示一个真实重点项目。下面的索引从 `projects` collection 自动读取公开项目，每个项目都链接到已有的 `/projects/[id]/` 档案页。

优点：

- 访客打开页面即可看到项目，而不是先看一张海报。
- 项目内容与现有 Build in Public 数据结构共用同一事实来源。
- 以后新增项目 Markdown 即可进入作品集，无需改页面结构。
- 少量真实项目也能成立，不需要用空卡片填满页面。

### 未采用：杂志式长篇项目故事

个性更强，但首屏阅读成本较高，并且每个项目都需要大量成熟文字和图片，不适合当前逐项补内容的节奏。

### 未采用：把作品集继续做成 3D 桌面扩展

互动感强，但会再次把作品隐藏在场景里，也会增加模型、坐标和交互维护成本。3D 桌面继续负责首页入口，作品集负责清楚地展示项目。

## 页面结构

### 1. 短介绍区

- 暖白背景，不使用整屏背景图和暗色遮罩。
- 标题为正常横排的“项目与作品”。
- 一句自然说明，明确这里只放可以讲清过程和结果的真实项目。
- 右侧显示当前公开项目数量与更新方式，作为信息而不是装饰。

介绍区高度控制在约 180 至 240 像素，1440×900 与 1920×1080 的首屏都必须露出重点项目。

### 2. 重点项目

第一个公开且 `featured: true` 的项目作为重点项目：

- 左侧使用该项目的真实页面截图，不使用通用流程图。
- 右侧展示项目名称、状态、阶段、简介和可核实结果。
- 整个区域提供清晰的“查看项目档案”入口。
- 当前首项为“个人主页实现｜Build in Public”。

重点项目采用有边界的横向版面，不做悬浮卡片，也不把内容放进多层卡片。

### 3. 项目索引

- 从 `projects` collection 读取所有 `draft: false` 项目。
- 推荐项目优先，其余按更新时间倒序。
- 每行展示编号、项目名称、类别、状态、更新时间和摘要。
- 每行都必须有合法站内详情地址。
- 首版只有一个真实项目也可以正常成立。

## 视觉规则

- 使用现有 `paper / white / ink / cold-green` 色彩体系。
- 标题横排，正文保持正常行宽，不使用竖排文字。
- 项目截图保持原始宽高比，禁止拉伸。
- 以真实截图、项目状态和结果作为视觉重点。
- 人像和 Q 版形象不作为作品集首屏主视觉；以后只在项目确有关系时使用。
- 不使用渐变球、通用科技流程图、重遮罩和模板式营销文案。

## 数据与扩展方式

页面只消费现有 `projects` collection。新增项目时建立一个项目 Markdown，并提供：

- 标题、简介、日期、更新时间。
- 状态、阶段、类别。
- 站内详情地址。
- 可选的结果数据和公开仓库地址。

项目可以通过可选的 `cover` 和 `coverAlt` 字段声明站内图片。没有封面的项目仍以文字索引正常显示，不使用通用占位图。本期重点项目截图由当前真实首页生成并压缩，不引入远程图片依赖。

## 验收标准

- 宽屏不再出现一字一行、标题压脸或正文超出首屏的问题。
- 1440×900 与 1920×1080 首屏都能看到重点项目名称、截图和详情入口。
- 作品集不再引用 `tech-cover-16x9-v1.png`。
- 页面只展示公开项目，并能进入对应项目档案。
- 图片无拉伸，页面无横向溢出，键盘焦点可见。
- 首页在相同分辨率下与 V0.9 基线保持零像素差。
- Vitest、Astro check、生产构建和现有发布 Gate 全部通过。
