# AI玩尔玉 Personal Homepage

An interactive desktop-style personal homepage built with Astro and Three.js.

The homepage treats a real desk as the navigation surface: the central monitor introduces AI玩尔玉, the side monitor opens activity records, the keyboard and mouse can be moved, and the pegboards are reserved for future badge and sticker stories.

## Local development

```powershell
npm install
npm run dev
```

Useful checks:

```powershell
npm test
npm run check
npm run build
```

The static output is generated in `dist/`.
